Deploy your LinkedIn OS

Real Canva integration · ~20 minutes · no terminal
What you'll have at the end: a real URL like nextflow-os-haris.vercel.app that you can open from any device. Click "Connect Canva" once → push slides directly into editable Canva designs from now on.

Before you start — checklist

  • An email you don't mind using for two accounts (Canva Developer + Vercel)
  • Your Anthropic API key (you already have this — same one you've been pasting in Settings)
  • About 20 minutes — most of it is waiting for sign-ups to verify

Step 1 of 7 — Create a Canva Developer app

1

Go to the Canva Developer Portal

Open canva.com/developers/apps in Chrome. Sign in with your normal Canva account (free works).

Click Create app. App type: Integration.

Name it Next-Flow LinkedIn OS. The other fields can stay default for now.

2

Copy the Client ID and Client Secret

After creating the app you'll see two long strings. Copy both and paste them in a notes app — you'll need them in Step 5.

Client ID looks like: OC-xxxxx-xxx-xxxx

Client Secret looks like: cnvc-xxxxxxxxxxxxxxxx

Heads up Canva shows the secret only once. If you close the page without copying, you can regenerate.

3

Set scopes

In the app's Scopes/Permissions section, enable: asset:read · asset:write · design:content:read · design:content:write · design:meta:read.

Save. Leave the redirect URI blank for now — you'll come back and fill it in after Vercel deploys (Step 6).

Step 2 of 7 — Push this folder to GitHub

4

Use GitHub Desktop (zero terminal)

Install GitHub Desktop if you don't have it. Sign in (or create a free GitHub account).

In GitHub Desktop: File → Add Local Repository → pick this folder: Documents/Claude/Projects/Next-flow content system AI AGENT/nextflow-os-vercel.

GitHub Desktop will say "this folder isn't a repository — would you like to create one?" → Yes.

Then click Publish repository. Name: nextflow-os. Uncheck "Keep this code private" if you want — either works.

Once published you'll have a GitHub URL like github.com/your-username/nextflow-os.

Step 3 of 7 — Deploy to Vercel

5

Sign up at Vercel

Go to vercel.com/signup → click Continue with GitHub. Authorize Vercel.

On the Vercel dashboard, click Add New… → Project. Find your nextflow-os repo → click Import.

Before clicking Deploy, expand Environment Variables and paste:

CANVA_CLIENT_ID = (the Client ID from step 2) CANVA_CLIENT_SECRET = (the Client Secret from step 2) COOKIE_SECRET = (any 50+ char random string — generate one at https://generate-secret.vercel.app/64) ANTHROPIC_API_KEY = (your Anthropic key — sk-ant-...)

Click Deploy. Wait ~90 seconds.

6

Copy your Vercel URL

When the deploy finishes, Vercel shows your URL — e.g. https://nextflow-os-haris.vercel.app. Click the URL — your OS should open.

Copy that URL — you need it for the next step.

Step 4 of 7 — Finish the Canva config

7

Add the redirect URI to your Canva app

Go back to your Canva developer app (canva.com/developers/apps) → open the app → find Authentication or Redirect URLs.

Add this URL (replace with your real Vercel domain):

https://YOUR-VERCEL-URL.vercel.app/api/canva/auth/callback

Save. This step is critical — without the exact redirect URI, Canva will reject the auth.

Optional but recommended: back in Vercel project settings → Environment Variables → add PUBLIC_URL = https://YOUR-VERCEL-URL.vercel.app → redeploy.

Step 5 of 7 — Test it

  • Open your Vercel URL in Chrome.
  • Click Settings top right → you should see Canva not connected.
  • Click Connect Canva → a popup opens to Canva → authorize → popup closes → status changes to Canva connected ✓.
  • Go to Create → write a story → Generate 4 Variations → pick a carousel one → click 🎨 Design graphic.
  • In Designer: upload 2-3 photos → set slide count → click Generate slides.
  • When slides render, click ☁ Push slides to Canva.
  • Wait ~15-30 seconds while each slide uploads.
  • Click → Open design in Canva → your design opens in Canva, editable.
If the Canva push fails: the most common cause is the redirect URI in your Canva app not matching your Vercel URL exactly (including /api/canva/auth/callback at the end). Double-check that. The second most common is forgetting to set COOKIE_SECRET in Vercel env vars.

Done

From now on, every time you want to use the OS, just open your Vercel URL. Bookmark it. No terminal, no installs, no commands — it just works.
